# Graphics and visual sources

These assets use the project's near-black, white, lavender, and violet palette. Illustrations communicate
personal continuity and biomimetic inspiration; technical diagrams describe the implemented
system. Consciousness-inspired framing is a design ambition, not a claim of sentience.

The hero is an illustration, not a product screenshot. Its text is also available in
the README for accessibility. The original launch image at the repository root is retained
as a historical asset and is not used for the current positioning.

Regenerate the SVG assets from the repository root:

```bash
python3 scripts/render_docs_graphics.py
```

The demo graphic is generated from actual extracted-memory lines only when the recorded
output confirms successful recall of pipeline-extracted records. If the demo changes, rerun it against a local stack, verify the output, and
update the visual summary to match. Do not present an invented model response as a recording.

Every graphic includes either SVG title/description metadata or Markdown alt text.
Keep source files in the repository and check both desktop and mobile rendering after edits.

[Compare the original, first revision, and three alternatives](banner-options/index.html).
Option C (biomimetic personal memory) was selected for the README.
