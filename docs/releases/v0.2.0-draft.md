# Draft: v0.2.0 — Persistent context through MCP

**Not published.** Proposed first tagged baseline; version/date pending release review.

Build a personal AI that remembers what matters. Agentic Memories exposes biomimetic
memory through MCP: its extraction pipeline turns conversations into useful memories
that a companion can recall later, with stored memories on your own infrastructure.

## Highlights

- **Connect through MCP.** Streamable HTTP at `/mcp` shares the existing API process and port.
  Discovery includes 39 application operations and four documentation tools, covering memory,
  profiles, scheduled intents, portfolios, and operations. REST remains supported.
- **Retrieve more relevant context.** Ordinary text recall uses measured cosine similarity,
  with fixes for procedural-memory relevance and duplicate results.
- **Track equity and option positions.** Portfolio APIs include contract fields, lifecycle
  status, grouped responses, and committed-collateral totals.
- **Operate with clearer diagnostics.** Connection-pool cleanup fixes and health statistics
  support diagnosis; an API-only update target leaves database containers running.
- **See conversation extraction in action.** A runnable MCP demo submits dialogue to the
  pipeline, prints actual extracted memories, then recalls those records through a new connection.

## Before upgrading

- Python 3.12 remains the supported runtime. Use the checked-in lockfile/export.
- Apply required database migrations, including 025 for options support, before relying
  on the corresponding API behavior. Back up persistent data first.
- Direct writes now honor explicit TTL values on every layer. Review callers that relied
  on previously ignored TTL values. PATCH null TTL clears expiration.
- Review filter-only retrieval ordering and pagination limits in the changelog.
- Configure MCP host/origin allowlists for remote access and protect `/mcp` as well as REST.
  The API does not enforce global authentication; MCP includes administrative operations.

## Verification and limitations

The [MCP verification report](../MCP-verification.md) records 840 passing regression tests,
one skipped test, and representative real backend round trips for its tested revision.
Rerun relevant checks on the final release commit; those results are not a benchmark or
coverage claim for every production configuration.

Live identity/proxy checks, load testing, and exhaustive production validation are not
implied. OpenAI is used for embeddings, with configured providers for extraction and
optional tracing. Self-hosted storage does not make the system fully offline.
